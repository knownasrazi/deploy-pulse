## Documentation

### What it does

Deployment pulse dashboard - mock status, logs, and health for your stack. It does one thing, well.

### Who it is for

- Vibe coders who prompt and ship
- Web developers who care about taste
- Anyone tired of heavy tools

### How it works

1. Clone the repo
2. Run the dev server for your language (React + Mock API)
3. Open, use, and export

```bash
git clone https://github.com/knownasrazi/deploy-pulse.git
cd deploy-pulse
# follow language quick start inside
```
