## Preview

> Feel your deploy pulse. - built for vibe coders and web developers who ship.

## Stack

- Vite + React + TypeScript
- Tailwind CSS (cream palette)
- Biome for lint and format

## Get started

```bash
git clone https://github.com/knownasrazi/deploy-pulse.git
cd deploy-pulse
bun install
bun run dev
```
deploy-pulse/
  src/
    App.tsx      # app shell
    index.css    # cream tokens
  index.html
  vite.config.ts
  package.json
```
